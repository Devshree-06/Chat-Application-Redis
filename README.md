# Chat Application with Redis

A real-time **Spring Boot** chat application powered by **Redis** for fast, scalable messaging. This project demonstrates how to build a modern chat system message persistence, and real-time updates.

---

## Features

- **Real-time Messaging**: Instant message delivery using WebSocket.
- **Redis Integration**: Efficient message storage and retrieval with Redis.
- **RESTful API**: Endpoints for user authentication, message history, and chat management.
- **Scalable Architecture**: Designed to handle multiple concurrent users.
- **Spring Boot**: Robust backend framework for rapid development.

---

## Tech Stack

| Technology       | Purpose                          |
|------------------|----------------------------------|
| Spring Boot      | Backend framework                |
| Redis            | In-memory data store for messages|          |
| Maven            | Dependency management            |
